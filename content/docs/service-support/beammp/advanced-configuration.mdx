## Startup Values

:::tip[Top-Tip]
Both Name & Description support decorators, this allows you to change the colour and add font styles to it. View [our guide on the topic](/docs/service-support/beammp/advanced-configuration#server-namedescription-decorations).
:::

| **Name**           | **Description**                                                                                                                                                                         | **Example**                            |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- |
| Authentication Key | This is required if you want your server to appear on the serverlist, [view our guide on obtaining a serverkey](/docs/service-support/beammp/getting-started#getting-a-server-key-step) | `7ca57fc4-e255-4ec9-bcf4-4da14456c0ba` |
| Name               | What your server will apear as on the server list.                                                                                                                                      | My Server                              |
| Description        | What your servers subtitle will show on the server list.                                                                                                                                | Please join my server!                 |
| Cars               | How many cars are allowed on your server at once.                                                                                                                                       | 12                                     |
| Map                | What map will be used when players join.                                                                                                                                                | `/levels/gridmap_v2/info.json`         |
| Max Players        | The max player that can join at once. **This value can only be modified by upgrading it on your billing panel**                                                                         |                                        |
| Private            | Should your server show on the serverlist. **You must have a Authentication Key set for this**                                                                                          | `false`                                |

## Server Name/Description Decorations

BeamMP provides special symbols to allow users to decorate their server name/description. Apply these symbols before any text you wish to stylise. (eg `^l^4Epic Server Name!`, for a bold red title)

| Value | Description                 |
| :---: | --------------------------- |
| `^r`  | Reset                       |
| `^p`  | Newline (descriptions only) |
| `^n`  | Underline                   |
| `^l`  | Bold                        |
| `^m`  | Strike-through              |
| `^o`  | Italic                      |
| `^0`  | Black                       |
| `^1`  | Blue                        |
| `^2`  | Green                       |
| `^3`  | Light blue                  |
| `^4`  | Red                         |
| `^5`  | Pink                        |
| `^6`  | Orange                      |
| `^7`  | Grey                        |
| `^8`  | Dark grey                   |
| `^9`  | Light purple                |
| `^a`  | Light green                 |
| `^b`  | Light blue                  |
| `^c`  | Dark orange                 |
| `^d`  | Light pink                  |
| `^e`  | Yellow                      |
| `^f`  | White                       |

## List of Allowed Tags

BeamMP provides tags to allow players to search for servers easier.
Multiple tags may be added together by seperating them by commas (eg `Freeroam,Racing`).

_Tags are not case sensitive._

- Age/Content:

  - `Mature/18+`

- Gameplay Types:

  - `Freeroam`
  - `Roleplay`
  - `Economy`
  - `Traffic`

- Racing Categories:

  - `Racing`
  - `Racing:NASCAR`
  - `Racing:Track`
  - `Racing:Drag`
  - `Racing:Rally`
  - `Touge`

- Off-Roading and Challenges:

  - `Offroad`
  - `Crawling`
  - `Dakar`
  - `Challenge`

- Destruction Events:

  - `Derby`
  - `Arena`

- Weather and Time Conditions:

  - `Snow/Ice`
  - `Rain`
  - `Night`
  - `Weather`

- Gamemodes:

  - `Gamemode`
  - `Gamemode:Racing`
  - `Gamemode:Rally`
  - `Gamemode:Drag`
  - `Gamemode:Derby`
  - `Gamemode:Infection`
  - `Gamemode:Cops-Robbers`
  - `Gamemode:Delivery`
  - `Gamemode:Sumo`

- Community and Events:

  - `Scenarios`
  - `Events`
  - `Leaderboard`

- Mods:

  - `Modded`
  - `Mod:BeamPaint`
  - `Mod:BeamJoy`
  - `Mod:CEI`

- Languages:

  - `Lang:English`
  - `Lang:Russian`
  - `Lang:French`
  - `Lang:Spanish`
  - `Lang:Portuguese`
  - `Lang:German`
  - `Lang:Polish`
  - `Lang:Arabic`

- Other:
  - `Vanilla`
  - `Moderated`
