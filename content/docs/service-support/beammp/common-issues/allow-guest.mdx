## Issue

Joining a service and seeing the "Guests are not enabled" message. This issue is primarily caused when you try to join a server as a guest and the server does not have guests enabled.

As of 2026, logging in as a guest is currently the only way due to service disruptions.

## Solutions

### General Config

1. Turn off your service before continuing
2. Navigate to, and open the `ServerConfig.toml` file in the root directory
3. Find the `AllowGuests` setting and set it to `AllowGuests = true`
4. Start your service.

### 3rd Party Server Resources

A common issue preventing guests is 3rd party resources.
The most prevalent are Cobalt Essentials and Nickel, however other moderation resources may exhibit similar behaviour.

We recommend either configurating these resources to allow for guests, or deleting the mods.
