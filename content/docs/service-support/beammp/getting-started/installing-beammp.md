This article explains how to install BeamMP so you can play BeamNG.drive multiplayer with your friends!

:::info[Prerequisites]
BeamMP requires that you own and have the latest version of BeamNG.drive installed on Steam. Pirated versions are not supported.
:::

:::warning[Windows Only]
BeamMP only officially supports Windows. Linux and macOS require extra steps, which are not detailed here.
:::

## Download the client \[step]

Head to the [BeamMP website](https://beammp.com) and click `Download Client`.

## Extract the installer \[step]

Open the downloaded ZIP, click `Extract All`, then `Extract` in the wizard that opens.

## Run the installer \[step]

1. Run `BeamMP_Installer.exe` by double-clicking it
2. Choose your desired language, and click `OK`
3. Agree to the license agreement, and click `Next`
4. Choose if you want a desktop shortcut, and click `Next`
5. Click `Install` to proceed with the installation
6. Wait for the install to complete, and click `Finish`

## 🎉 BeamMP is now installed! \[step]

The BeamMP Launcher will open and automatically launch BeamNG.drive, click `Launch` to play. Once the game has loaded, click `Multiplayer` to play BeamMP.
