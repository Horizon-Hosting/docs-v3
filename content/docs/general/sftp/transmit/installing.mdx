---

:::warning[Transmit 5 is premium software.]
There's a 7-day free trial, after that you'll need to pay a one-off license charge of $45.
:::

## Download the installer [step]
1. Go to the [Transmit 5](https://panic.com/transmit/) website
2. Press `Try It`
3. Press `Download Transmit Now!` and wait for the download to finish

## Run the installer [step]
1. Extract the downloaded ZIP folder. (It should be named like: `Transmit 5.x.x.zip`)
2. Move the extracted `Transmit` application into the Applications folder
3. Delete the downloaded `.zip` file

## 🎉 Transmit is now installed! [step]
You have a 7-day free trial of Transmit before you need to purchase a license key.
