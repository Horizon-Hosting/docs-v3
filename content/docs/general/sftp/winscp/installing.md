---
title: Installing WinSCP
description: How to install WinSCP
type: How To
---

## Download the installer \[step]

1. Go to the [WinSCP download](https://winscp.net/eng/download.php) page
2. Press the `Download WinSCP x.x.x` button and wait for the download to finish

## Open the installer \[step]

1. Open the program (It should be named like `WinSCP-x.x.x-Setup.exe`)
2. Press `Install for me only` (You can install for all users; however, this requires the admin password)

## Follow the installer steps \[step]

1. Read the WinSCP License Agreement, and press `Accept`
2. Select the `Typical installation` option, and press `Next`
3. Select the `Commander` option, and press `Next`
4. Confirm the settings are as desired, and press `Install`
5. If you followed the above steps, the default settings should be good.
6. Wait for the install to complete
7. Unselect `Open Getting started page`, and press `Finish`

## 🎉 WinSCP is now installed! \[step]

*If you selected `Launch WinSCP`, it will automatically open WinSCP.*
