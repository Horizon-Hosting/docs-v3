## Download the installer [step]

:::warning[Do not press the green `Download FileZilla Client` button]
    * It will flag up in your antivirus as adware
    * It will prompt you to install adware like Avast and other tools during the install
    * **IT IS NOT HARMFUL OR MALWARE. *Just irritating***
:::

1. Go to the [FileZilla download](https://filezilla-project.org/download.php?type=client) page
2. Press `Show additional download options` 
3. Select the Windows (64bit x86) recommended download and wait for the download to finish

## Run the installer [step]
1. Open the download installer (It should be named like: `FileZilla_x.x.x_win64-setup.exe`)
2. There may be a pop-up asking for permission to make changes, approve it

## Follow the installer steps [step]
1. Read the FileZilla License Agreement, and press `I Agree`
2. Select `Only for me (YOUR USERNAME)`, and press `Next >`
3. Select the components you'll require, and press `Next >`
4. The defaults should be fine for most use cases.
5. Defaults: FileZilla Client, Icon sets, Language files, & Shell Extension. Anything more is optional.
6. Either choose a different install location, or continue by pressing `Next >`.
7. Confirm Start Menu folder name, and press `Install`
8. Wait for the install to complete, and press `Next >`

## 🎉 FileZilla is now installed! [step]
If you selected `Start FileZilla now`, it will automatically open FileZilla.
