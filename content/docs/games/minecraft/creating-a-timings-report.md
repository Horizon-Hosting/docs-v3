---
title: Creating a Timings Report
description: How to create a timings report to diagnose and identify server lag.
type: How To
---

:::info[Spigot / Paper only]
Timings reports are only supported on Spigot and Paper based servers.
:::

When opening a support request for server lag, we'll often ask for a timings report. This lets us pinpoint exactly what's causing your server to lag.

:::tip[Capture during lag]
Make sure your timings report is captured during a period of actual server lag, and that it spans at least 10 minutes.
:::

## Start timings \[step]

Run `/timings on` in-game, or `timings on` in the console.

## Let it run \[step]

Let the server run as normal for 10-15 minutes while it's lagging. The report is generated in the background.

## Generate the report \[step]

Run `/timings report` in-game, or `timings report` in the console.

## 🎉 Done \[step]

The server will output a link in the console/chat. Send this link to your technician along with your support request.
