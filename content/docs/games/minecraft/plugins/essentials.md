---
title: Installing EssentialsX
description: How to install EssentialsX on your Minecraft server.
type: How To
---

EssentialsX is the actively maintained fork of the classic Essentials plugin, adding core server commands (`/home`, `/warp`, `/tpa`, `/kit`, economy, and more) that most other plugins build on top of.

## Download EssentialsX \[step]

Go to the [EssentialsX download page](https://essentialsx.net/downloads.html) and download the latest build, along with any optional modules you want (such as EssentialsXChat or EssentialsXSpawn).

## Upload to your service \[step]

Using either the panel file manager or [SFTP](/games/sftp), upload the downloaded `.jar` file(s) into your `plugins` folder.

## Restart your server \[step]

Go back to the console tab and restart your server. EssentialsX will generate its default configuration files inside `plugins/Essentials/` on first load.

## 🎉 Done \[step]

Open `plugins/Essentials/config.yml` using [SFTP](/games/sftp) or the file manager to configure things like starting balance, kits, and enabled commands.
