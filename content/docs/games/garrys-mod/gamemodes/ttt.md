Trouble in Terrorist Town (TTT) is a social-deduction gamemode where a hidden group of traitors try to eliminate the innocent crew without being caught. Unlike DarkRP, TTT ships bundled with every Garry's Mod install, so there's nothing to download.

## Set the gamemode \[step]

Go to the startup section of your service and set the "Gamemode" field to `terrortown` (this is the internal folder name TTT uses, case sensitive).

## 🎉 Done \[step]

Restart your service. You'll need at least one other map designed for TTT (map names are typically prefixed `ttt_`) since Sandbox maps aren't built with traitor traps or weapon spawns in mind. Popular TTT maps are available on the [Steam Workshop](https://steamcommunity.com/app/4000/workshop/), which you can add via a [collection](/games/garrys-mod/getting-started#add-a-collection-step).

## Common config

TTT specific `server.cfg` convars (round time, karma, haste mode, etc.) can be set alongside the general options covered in [our Garry's Mod server configuration guide](/games/garrys-mod/server-configuration).
