---
title: Installing Cyberduck
description: How to download and install the Cyberduck SFTP client on macOS or Windows.
type: How To
---

## Download the installer \[step]

1. Go to the [Cyberduck download](https://cyberduck.io/download/) page
2. Press `Cyberduck for Windows` and wait for the download to finish

## Run the installer \[step]

1. Open the downloaded installer (It should be named like: `Cyberduck-Installer-x.x.x.xxxxx.exe`)
2. Press the `Install` button
3. There may be a pop-up asking for permission to make changes, approve it
4. Press `Close`

## 🎉 Cyberduck is now installed! \[step]

Cyberduck doesn't automatically open after install, you'll need to manually open it from the start menu.
